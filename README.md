Customer Behavior Analysis

📌 Project Overview

This project analyzes customer shopping behavior to understand purchasing patterns, product categories, subscription status, seasonal trends, and payment preferences.

Python is used for data analysis, SQL for querying data, and Power BI for creating an interactive dashboard.

🎯 Project Objectives

- Analyze customer shopping patterns.
- Clean and prepare data for analysis.
- Perform SQL queries to identify useful insights.
- Compare sales and revenue across product categories.
- Analyze seasonal purchasing trends.
- Visualize key metrics using Power BI.

📂 Dataset

The project uses a Customer Shopping Behavior dataset containing customer information, product categories, purchase amounts, subscription status, payment methods, seasons, and review ratings.

🛠️ Tools and Technologies

- Python
- Pandas and NumPy
- MySQL / SQL Server
- Power BI
- GitHub
- Gamma for presentation creation

🔄 Project Workflow

1. Data Loading: Load the dataset into Python.
2. Data Cleaning: Check missing values, duplicates, and data types.
3. EDA: Explore customer purchasing patterns and shopping trends.
4. SQL Analysis: Query data using filtering, grouping, and aggregate functions.
5. Dashboard Development: Create charts, KPI cards, and interactive filters in Power BI.
6. Reporting: Summarize findings and prepare a project presentation.

📊 Dashboard Highlights

Key Performance Indicators

- Number of Customers: Displays the customer count.
- Average Purchase Amount: Shows the average purchase amount.
- Average Review Rating: Displays the average customer review rating.

Visualizations

- Percentage of customers by subscription status
- Revenue by category
- Sales by category
- Purchase amount by season
- Payment method distribution

Interactive Filters

- Subscription Status
- Gender
- Category

💡 Business Value

The dashboard helps explore customer purchasing patterns, category performance, subscription distribution, seasonal trends, and payment preferences.

▶️ How to Run

Python

Install the required libraries:

pip install pandas numpy matplotlib seaborn jupyter

Open the Python file or notebook, update the dataset path if needed, and run the analysis.

SQL

1. Open MySQL Workbench or SQL Server Management Studio.
2. Import the dataset into a database table.
3. Open the SQL queries file.
4. Execute the queries using the correct table and column names.

Power BI

1. Install Power BI Desktop.
2. Open "customer_behavior2.pbix".
3. Refresh the data source if required.
4. Explore the dashboard using the available filters.
