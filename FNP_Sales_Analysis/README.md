# FNP Sales Analysis Dashboard

Project Overview

This project focuses on analyzing sales data to understand business performance, customer behavior, and revenue trends using Microsoft Excel.

Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Dashboard

Key KPIs

- Total Orders
- Total Revenue
- Average Order Value
- Average Customer Spend
- Order and Delivery Time

Analysis Performed

- Revenue by Category
- Revenue by Occasion
- Revenue by Month
- Revenue by Hour
- Top 5 Products by Revenue
- Top 10 Cities by Orders

Dashboard Features

- Interactive Dashboard
- Dynamic Slicers
- Visual Data Analysis
- KPI Cards

Objective

To analyze sales performance and generate meaningful business insights to support better decision-making.
